# Bundled fonts

All fonts are licensed under the **SIL Open Font License 1.1** (https://openfontlicense.org), which allows use,
embedding and redistribution, including commercially, provided the fonts are not sold on their own.
Files are fetched by `scripts/fetch_fonts.py` (not committed) from https://github.com/google/fonts.

| File | Family | Use |
|---|---|---|
| Inter.ttf | Inter (Rasmus Andersson) | clean sans |
| BebasNeue-Regular.ttf | Bebas Neue (Dharma Type) | condensed caps |
| Anton-Regular.ttf | Anton (Vernon Adams) | heavy caps |
| Montserrat.ttf | Montserrat (Julieta Ulanovsky et al.) | geometric sans |
| PlayfairDisplay.ttf | Playfair Display (Claus Eggers Sorensen) | editorial serif |
| JetBrainsMono.ttf | JetBrains Mono | typewriter |
| NotoSans.ttf, NotoSansArabic.ttf, NotoSansSC.ttf | Noto (Google) | fallbacks for Latin/Cyrillic/Greek, Arabic (RTL), Simplified Chinese |

Custom fonts: place a TTF/OTF under `~/Clipforge/fonts/` and reference its file name in a template or brand kit.
